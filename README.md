# LinkedIn Personal Branding Landing Page 🚀

A responsive landing page created for a LinkedIn personal branding service.

🌐 Live Demo

https://webinar-g87c5imk4-web-5ff8.vercel.app/

📌 Project Overview

This project is a modern landing page designed to present LinkedIn personal branding services, achievements, customer reviews, FAQs, and a lead-generation form.

The project helped me understand how different design, development, data-handling, and deployment tools can be combined to build and publish a functional web project.

✨ Features

- Responsive landing page
- Hero section with clear call-to-action
- Achievements section
- Lead generation form
- ₹1 LinkedIn Audit section
- Customer reviews
- FAQ section
- Final call-to-action
- Responsive design

 🛠️ Tools & Technologies

- HTML
- CSS
- JavaScript
- Figma
- Google Stitch
- Google Sheets
- Google Apps Script
- GitHub
- Vercel

🔄 Development Workflow

1. Planned the project requirements and content with ChatGPT.
2. Generated the initial UI concept using Google Stitch.
3. Refined the design in Figma.
4. Integrated form and data handling using Google Sheets and Google Apps Script.
5. Uploaded the project to GitHub.
6. Deployed the website using Vercel.

 🤖 AI-Assisted Development

AI-assisted tools were used during the project for requirement planning, UI generation, and code assistance.

The project was used as a practical learning experience to understand the workflow from idea → design → integration → deployment.

 📚 Learning Outcome

Through this project, I gained practical experience in:

- Converting requirements into a web interface
- Working with UI design tools
- Connecting forms with Google Sheets
- Using Google Apps Script
- Managing projects with GitHub
- Deploying a live website using Vercel
